# 3d-slope-stability-comparative-case-study
An optimized 3D limit-equilibrium slope stability simulation pipeline linking UAV photogrammetry (Pix4Dmapper) and spatial downsampling (QGIS) to the USGS Scoops3D execution engine. Evaluates global highwall failure vectors across five countries using a static crystalline limestone terrain baseline under varying saturation and seismic stresses.
